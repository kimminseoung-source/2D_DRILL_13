# DRILL 13 — 아이템 모드

2026-11-10 수업의 게임 프레임워크를 기반으로 아이템 선택 모드를 구현했습니다.

## 실행
Python 3.12 환경에서 다음 명령을 실행합니다.

```powershell
python -m pip install -r requirements.txt
python main.py
```

VS Code에서 이 과제 폴더를 열고 `DRILL 13: main` 디버그 구성을 선택해 F5로 실행할 수도 있습니다. `main.py`가 시작 파일입니다. 리소스는 코드가 있는 폴더를 기준으로 찾으므로 다른 작업 디렉터리에서도 실행할 수 있습니다.

## 조작
| 화면 | 키 | 동작 |
|---|---|---|
| 로고 | 자동 | 2초 후 타이틀 |
| 타이틀 | Enter | 플레이 시작 |
| 플레이 | 좌우 방향키 | 이동 |
| 플레이 | Space | 선택한 공 발사; 수면 중에는 먼저 일어나기 |
| 플레이 | I | 아이템 선택 화면 |
| 아이템 | 0 / 1 / 2 | 볼 없음 / 작은 볼 / 큰 볼을 선택하고 복귀 |
| 아이템 | ESC / I | 선택을 변경하지 않고 복귀 |
| 플레이 | P | 일시중지 / 재개 |
| 타이틀·플레이·로고 | ESC | 종료 |
| 모든 화면 | 창 X | 종료 |

숫자패드 0/1/2도 지원합니다. 초기 선택은 작은 볼입니다. 0번은 새로운 발사를 막고 기존 공은 유지합니다. 작은 공은 21×21, 큰 공은 41×41입니다. 5초 동안 가만히 있으면 캐릭터가 잠들며, Space로 깨울 수 있습니다.

아이템 선택 중에는 캐릭터·공·수면 타이머가 정지합니다. 기존 게임을 새로 만들지 않고 모드 스택으로 복귀합니다. 선택 화면에서 복귀하면 방향키를 다시 눌러 이동합니다. P 일시중지 중에는 I를 무시하여 두 화면이 겹치지 않습니다.

## 검증
```powershell
python -B -m unittest discover -s tests -v
```
테스트는 실제 SDL 캔버스를 열고 게임 이미지와 캐릭터를 사용합니다. 그래픽 환경이 필요합니다. 검증 항목과 결과는 `VERIFICATION.md`를 참고하세요.

## 출처와 구성
- `boy.py`, `ball.py`, `grass.py`, 게임 프레임워크와 기존 이미지: 오늘 수업의 LEC15_Game_Framework 코드/리소스에서 시작했습니다.
- `item_mode.py`, `item_state.py`: 아이템 선택과 상태 보관.
- `item_select.png`: 수업에서 제공한 아이템 선택 안내 이미지.
- 한글 안내 PNG: 개발 시 렌더링한 텍스트 이미지이며 실행 시 외부 폰트나 Pillow가 필요하지 않습니다.
- `PRD.md`: 과제 요구사항과 승인한 개발 계획.
